# GlobeTrotter

GlobeTrotter is a travel planning platform that helps users create personalized trips, manage multi-city itineraries, estimate travel budgets, discover destinations and activities, and securely share travel plans.

## Features

- User Authentication
- Personalized Trip Planning
- Multi-City Itineraries
- Destination & Activity Discovery
- Budget Estimation
- Transportation Planning
- Saved Destinations
- Trip Sharing
